A QUICK INTRODUCTION

From one issue
to the whole picture.

Ripple follows the connections between services to help you understand what might be affected.

  1. Choose a service.Ledger DB is a good starting point. We assume it has a reported problem.
  2. Run an investigation.Graph evidence follows stored connections. AI investigator also uses Gemini to write a brief from graph tool results.
  3. Read the evidence.Checkout → Payments → Ledger DB means Checkout depends on Payments, which depends on Ledger DB.
  4. Approve a response.Create a local task for the responsible team after reviewing the findings.
Connecting AI

Add your Gemini key to .env as GEMINI_API_KEY, then restart the app. Never add it to source code or share it.
